# BlobWorm

Гибрид Agar + Slither: шары и черви, комнаты, голос, миникарта.

Друзья видят друг друга в мире (силуэт + ник), слышат в комнате (WebRTC). Публичный матч 30 мин / до 50 игроков.

## Быстрый старт (ПК)

```bash
npm install
npm start
```

Открой **http://localhost:5173**

Нужен именно `npm start` (Node-сервер) — иначе комнаты и голос не работают.

## Играть с друзьями в колледже (одна Wi‑Fi)

1. На одном ПК: `npm install` → `npm start`
2. В консоли появится адрес вида `http://192.168.x.x:5173`
3. Друзья открывают этот адрес в браузере (Chrome/Edge)
4. **Приватная комната** → создай код → друзья вводят тот же код → хост жмёт **Старт**

Микрофон в Chrome по HTTP работает только на `localhost`. На IP в LAN голос может быть ограничен — для голоса лучше онлайн-деплой (HTTPS ниже).

## Онлайн для всех (GitHub + Render)

1. Репозиторий уже на GitHub (этот проект).
2. Зайди на [render.com](https://render.com) → **New** → **Blueprint** → подключи репо `blobworm`.
   - Или **Web Service** → Root: репо → Build: `npm install` → Start: `npm start`.
3. Дождись деплоя → получишь URL вида `https://blobworm-xxxx.onrender.com`
4. Эту ссылку кидай друзьям. Комнаты и голос работают по HTTPS/`wss`.

Free-тариф Render засыпает после ~15 мин без игроков — первый заход может подождать ~30–60 сек.

Проверка сервера: `GET /health`

## Управление

**Шар:** Space — Split · W — Eject · Q — Pulse (4с защита большого куска, КД 25с)  
**Червь:** ЛКМ/Space — Boost · E — Инвиз (с 500+ счёта)

Телефон: джойстик + кнопки способностей.

## Структура

- `server/index.js` — Express + WebSocket `/ws`
- `js/` — клиент (игра, сеть, голос, UI)
- `index.html` / `css/` — оболочка
